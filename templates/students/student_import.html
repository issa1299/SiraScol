Comment ça marche

1. Choisissez l'année puis la classe (un seul import par classe).

2. Téléchargez le modèle Excel et remplissez une ligne par élève.

3. Déposez le fichier : SiraScol vérifie les données et affiche un aperçu (aucune écriture).

4. Confirmez l'import : matricules et comptes sont créés (identifiant 2026.0001 / mot de passe 2026-0001).

5. Un rapport d'erreurs Excel est téléchargeable si certaines lignes ont été ignorées.

Doublons et lignes invalides sont signalés avant confirmation et jamais importés.

Colonnes du fichier : Nom, Prénom, Sexe (M/F), Date de naissance, Date d'inscription, Téléphone, Lieu de naissance, Adresse, Nom du parent (« Prénom Nom »), Téléphone parent, Relation (Père/Mère/Tuteur).
La classe et l'année ne sont pas dans le fichier : elles sont prises dans le formulaire.
