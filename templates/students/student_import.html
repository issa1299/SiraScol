Comment ça marche

1. Téléchargez le modèle CSV et remplissez une ligne par élève.

2. Le matricule est généré automatiquement (ex. 2026-0001).

3. Un compte est créé : identifiant 2026.0001, mot de passe 2026-0001.

4. L'élève est inscrit dans la classe indiquée pour l'année choisie.

Les lignes en erreur sont ignorées et signalées dans le rapport ; les autres sont importées.

Colonnes reconnues : Nom, Prénom, Sexe (M/F), Date de naissance, Date d'inscription, Classe, Année scolaire, Téléphone, Lieu de naissance, Adresse, Nom du parent (« Prénom Nom »), Téléphone parent, Relation (Père/Mère/Tuteur).
