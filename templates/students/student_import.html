Télécharger le modèle

Comment ça marche

1. Choisissez l'année puis la classe (un seul import par classe).

2. Téléchargez le modèle et remplissez une ligne par élève de cette classe.

3. Le matricule est généré automatiquement (ex. 2026-0001).

4. Un compte est créé : identifiant 2026.0001, mot de passe 2026-0001, et l'élève est inscrit dans la classe choisie.

Les lignes en erreur sont ignorées et signalées dans le rapport ; les autres sont importées.

Colonnes du fichier : Nom, Prénom, Sexe (M/F), Date de naissance, Date d'inscription, Téléphone, Lieu de naissance, Adresse, Nom du parent (« Prénom Nom »), Téléphone parent, Relation (Père/Mère/Tuteur).
La classe et l'année ne sont pas dans le fichier : elles sont prises dans le formulaire.
