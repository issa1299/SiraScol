Caméra indisponible ?

  • Téléphone : autorisez la caméra pour ce site dans les réglages du navigateur.
  • HTTP (IP locale) : la caméra est bloquée hors HTTPS. Utilisez le matricule ou accédez en HTTPS.
  • Chrome mobile : icône 🔒 → Autorisations → Caméra → Autoriser, puis rechargez.
  • Caméra occupée : fermez les autres applications qui l'utilisent.

Solution immédiate

Cliquez sur « Saisir le matricule » et tapez le numéro indiqué sur la carte (ex. 2026-0001).
